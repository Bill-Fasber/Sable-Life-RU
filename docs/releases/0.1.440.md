# Sable Life · 0.1.403-fix1 → 0.1.440

[English changelog](0.1.440_EN.md)

汇总 0.1.403-fix1 之后至 0.1.440 的主要更新，按功能分类，同一功能的多次调整合并为当前行为。

## New Modules · 新增模块

- **推进（Propulsion）**：在一个标记点施加爆发冲量或持续推力，可选标记面方向或北、南、东、西、上、下六个世界方向。支持角度偏移、持续时间、间隔及推进方向限速，保留物理惯性，偏心施力可产生转动。世界方向不随机体旋转，旧设置默认沿用标记面；普通预览和观察工具与实际推力方向一致。
- **运动阻尼（Motion Damping）**：按世界方向或标记面的局部方向，分别设置六方向的制动强度和速度阈值。支持信号控制、定时生效及 Move Set，六方向集中在紧凑单页编辑。
- **断肢破坏（Part Break）**：通过触发器或监听部位的累计伤害，破坏单点或同一子结构上的两点范围，支持破坏音效。
- **消息显示（Message Display）**：依次发送聊天、标题或操作栏消息，支持颜色、副标题、接收半径和每条消息发完后的等待时间。可由死亡事件触发，本体清理后仍能发送剩余消息。

## Module Changes · 模块更新

- **信号逻辑（Signal Logic）**：弹窗选择 AND、OR、XOR、NAND、NOR、XNOR、NOT；支持多条输入规则，以及两个频道信号强度的 `=`、`≠`、`>`、`<`、`≥`、`≤` 比较。
- **无线频道（Wireless Channel）**：直接绑定多个红石输出面，各面输出该频道当前强度。支持单独命名、标记、预览、移除及分页；预览结束返回原输出面列表和页码。
- **无线红石（Wireless Redstone）**：一个模块可使用多个共用属性的输出面。第 1 面保留原有底部按钮，第 2 面起在属性页管理，预览显示对应编号。
- **多面输出上限**：每个无线频道／无线红石模块默认最多 16 面，服务器可设为 1–64。旧档已保存的更多输出面继续保留和运行，仅新增受限。
- **自动朝向（Auto Facing）**：可按模块名和编号选择同核心的 Target Sensor，跟随该感应器选中的目标；绑定可随存档、蓝图及整套配置复制保留。
- **信号转向（Signal Turning）**：新增随机水平转向，可设置随机角度范围；新增与陀螺仪同时运行的开关，默认关闭。
- **直线移动（Linear Movement）**：新增标记世界位置作为终点的模式，可由信号或招式触发。
- **Move Set**：新增“沿用选招目标”，让支持的瞄准型攻击优先攻击选招时的目标；新招式默认开启，旧设置保留。
- **累计伤害触发**：可选择监听整个生命体或指定 Sable 子结构，标记部位模式可直接预览监听范围。
- **部位伤害修正**：每条规则可分别设置通用、近战及弹射物直击修正；近战和弹射物可单独覆盖通用值，或沿用通用值。
- **攻击索敌**：为更多内置攻击统一补充视线遮挡开关，迫击炮目标位置模式也可单独设置。已有存档保留原有索敌行为。
- **持续伤害区域**：新增生成后延迟爆破一次，可控制地形破坏、粒子及音效。

## Arena & Blueprints · 场地与蓝图

- **多阶段战斗**：通过蓝图生成接替下一阶段，或生成参与同一场战斗的单位。场地统一追踪战斗结束与重置，避免第一阶段死亡后过早刷新。
- **战斗限时**：可开启跨阶段计时，默认 5 分钟；超时清理并恢复第一阶段。
- **倒数提醒**：开战和剩余时间提示支持自定义文字、颜色及示例，可选择标题或聊天栏，只通知同维度场地附近的玩家。
- **场地公告**：可分别设置刷新成功与被击败的全服公告，留空关闭；玩家死亡倒计时可独立设置。
- **蓝图选择**：调整服务器蓝图选择页，支持选择生成后是否自动激活核心。

## Core & Tools · 核心与工具

- **自动补能**：生存核心的补能输入槽支持漏斗及兼容物品管道，可开启自动确认补能。输入物品随核心移动，同世界挖下再放置可保留。
- **观察工具（Inspection Tool）**：绑定核心后勾选多个模块，持续显示范围、方向和标记，并附带模块名称；重叠名称分行显示。使用自绘观察环贴图及手持工具模型，原版望远镜保留缩放功能。
- **观察工具合成**：1 个望远镜＋1 个红石粉，无序合成 1 个观察工具，物品栏和工作台均可使用。获得望远镜后解锁配方书，中英文手册补充合成、绑定与持续预览步骤。
- **核心遥控器（Core Remote）**：绑定或换绑同维度已加载核心，远程打开面板并激活生命核心，遵守对应权限及生存能量规则。
- **指挥棒（Command Wand）**：临时指定生物或坐标，分别控制自动朝向、目标对准、直线移动及支持的武器跟随目标；缺少已保存开关时，默认开启武器跟随。
- **生物类型白名单**：支持搜索原版和模组生物，新增被动／中立生物预设，可排除指定类型的自动索敌。
- **模块管理**：支持多选及批量分组；每核心默认模块上限提高至 256，服务器配置范围为 16–1024，并提示大型核心可能加载较慢。
- **消息权限**：生存核心消息显示默认关闭，服主开启后只允许同维度范围内接收；全服广播仅限普通生命核心。
- **领地与远程权限**：拒绝提示显示具体原因；新增默认关闭的配置，允许服主在未适配领地接口时开放遥控器和远程检查工具，已适配的领地权限仍会校验。

## Visuals & UI · 表现与界面

- **可染色粒子**：新增 `!`、`?`、`...`、`×`、`⚡`、金属碎屑和故障电火花，支持 RGB、大小及寿命设置，并整理符号轮廓。
- **曳光拖尾**：枪武器、箭矢发射、迫击炮和悬浮追踪弹可切换为曳光，颜色、长度和宽度可调。
- **受击粒子**：普通与生存生命核心可自定义结构命中的粒子种类、数量及散布。
- **径向模糊**：背对发射点也可显示模糊，转向发射点时平滑过渡，保留距离衰减。
- **预览与排版**：断肢破坏可同时显示监听结构与破坏范围；精简多处预览长说明，调整页码、输入框及按钮对齐，更新中英文手册。

## Compatibility · 兼容更新

- **Let it Walk!**：兼容仍连接的机械腿等附属结构受伤，将伤害交给主体核心；同一投射物或爆炸按核心去重，减少多个部件和 Hybrid 重复扣血。
- **TaCZ Tactical Breaching**：修复其取消结构命中事件后，子弹击中非核心方块漏扣生命的问题，保留原模组的破坏与穿透处理。
- **Create: Gunsmithing / NTGL**：补充弹丸、火箭、手雷及近战对生命化结构的伤害兼容。
- **LittleTiles**：内置可选的客户端网格恢复补丁，对已识别的网格失效或上传失败路径请求有限次数的原生重建，缓解部分结构方块透明问题。可在客户端配置关闭，仅在依赖版本和接口匹配时启用。

## Bug Fixes · 主要修复

- 修复多部件蓝图生成后，关节尚未恢复就误判断开、丢失标记或提前触发断肢清理的问题；自动激活等待必要的连接与标记就绪。
- 修复断肢破坏和累计伤害触发的“标记部位”操作可能导致断线。
- 修复箭矢发射模块混用世界与结构坐标，导致碰撞查询范围过大和漏判目标。
- 实体受击框忽略药水状态及燃烧计时；修正同源接触攻击在多个受击框上重复扣血的问题，保留直接命中伤害。
- 改进结构清理的异常重试与 Sable 原生清理回退，单个任务失败后保留待清理记录。
- 隔离 Java 附属模块的启动、运行及停止链接错误，保留其设置，让其他模块和核心继续运行。
- 修正场地刷新／击败公告在复制、保存和重载后的初始化一致性。
- 补齐发布 JAR 与源码包中的 MIT 和模板许可证文件。

## Addon Support · 扩展支持

- 新增 **Java 模块 API**，允许附属注册模块、属性、标记和服务端行为。
- 新增 **JSON Datapack 模块**及示例，支持 `/reload`，每模块最多 8 个数值属性；定义暂时缺失时保留已有设置，恢复定义后可继续使用。
- Java 附属与 Datapack 模块均可按核心类型单独禁用，原有全局禁用配置继续生效。
