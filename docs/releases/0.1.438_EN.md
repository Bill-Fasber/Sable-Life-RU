# Sable Life · 0.1.403-fix1 → 0.1.438

[中文更新说明](0.1.438.md)

Major changes since 0.1.403-fix1, grouped by feature. Repeated adjustments are combined into their current behavior. These notes describe the current local 0.1.438 test build.

## New Modules

- **Propulsion**: Apply an impulse or continuous thrust at one marked point, with direction angles, duration, interval and optional directional speed control. Retains physical inertia; off-center thrust can produce rotation.
- **Motion Damping**: Configure braking strength and speed thresholds separately for six world or marked-face directions. Supports signals, timed activation and Move Sets, with a compact single-page direction editor.
- **Part Break**: Break a marked block or a two-point region on one substructure using a trigger or accumulated part damage. Supports a break sound.
- **Message Display**: Send sequences of chat, title or action-bar messages with formatting, subtitles, recipient radius and a wait after each message. Death events can start a sequence that continues after the body is removed.

## Module Changes

- **Signal Logic**: Choose AND, OR, XOR, NAND, NOR, XNOR or NOT in a picker. Supports multiple input rules and direct channel-strength comparisons: `=`, `≠`, `>`, `<`, `≥`, `≤`.
- **Wireless Channel**: Bind multiple redstone output faces directly to a channel's current strength. Each face can be named, marked, previewed or removed, with pagination. Preview returns to the original face list and page.
- **Wireless Redstone**: Use multiple output faces sharing one module's settings. Face 1 keeps the original bottom buttons; additional faces are managed in the properties. Previews display face numbers.
- **Output-face limits**: Each channel or Wireless Redstone module defaults to a maximum of 16 faces, configurable from 1 to 64. Previously saved faces above the limit remain intact and operational; only additions are restricted.
- **Auto Facing**: Select a Target Sensor on the same core by name and number, then follow its chosen target. Bindings survive saves, blueprints and full configuration copies.
- **Signal Turning**: Added random horizontal turns with an adjustable angle range, plus an option to turn while the Gyroscope is correcting. The latter is off by default.
- **Linear Movement**: Added a marked world destination, usable through signals or Move Sets.
- **Move Set**: Added an option for supported aimed attacks to use the target selected for the move. Enabled for new moves; existing settings are retained.
- **Damage Accumulation Trigger**: Listen to the whole creature or one Sable substructure, with a preview for the marked part.
- **Part Damage Modifier**: Each rule can set general, melee and direct projectile modifiers. Melee and projectile settings can override or inherit the general value.
- **Attack targeting**: Added consistent line-of-sight options to more built-in attacks, including Mortar's target-position mode. Existing saves retain their targeting behavior.
- **Persistent damage areas**: Added a delayed, one-time explosion with terrain, particle and sound options.

## Arena & Blueprints

- **Multi-stage encounters**: Blueprint generation can create the next boss phase or additional encounter participants. The arena tracks encounter completion and resets across phases.
- **Battle time limit**: Optional timer across phases, defaulting to five minutes. Expiry clears the encounter and restores its first phase.
- **Countdown notices**: Customize the start and remaining-time messages, with formatting and examples. Choose titles or chat; notices go to nearby arena players in the same dimension.
- **Arena announcements**: Separate global spawn-success and defeat announcements; leave either blank to disable it. Player-death countdowns can be configured separately.
- **Blueprint selection**: Revised the server blueprint picker and added control over automatic core activation after placement.

## Core & Tools

- **Automatic refueling**: Survival Core fuel input accepts hoppers and compatible item pipes, with optional automatic confirmation. Stored input moves with the core and survives breaking and replacing it in the same world.
- **Inspection Tool**: Bind a core and select multiple modules for persistent range, direction and mark previews with module names. Overlapping names use separate lines. The independent item temporarily uses the spyglass texture; vanilla spyglasses retain zoom.
- **Core Remote**: Bind or rebind a loaded core in the same dimension, open its panel and activate life cores remotely, subject to permissions and Survival Energy rules.
- **Command Wand**: Temporarily designate entities or coordinates, with separate controls for Auto Facing, Target Alignment, Linear Movement and supported weapon targeting. Weapon following defaults to on when no saved setting exists.
- **Mob type whitelist**: Search vanilla and modded types, with Passive and Neutral presets, and exclude selected types from automatic targeting.
- **Module management**: Added multi-selection and batch grouping. Default capacity is now 256 modules per core, configurable from 16 to 1024, with a warning about loading larger cores.
- **Message permissions**: Survival Core messages are disabled by default. When enabled by the server, recipients must be in range and in the same dimension. Global broadcasts remain limited to ordinary Heart Cores.
- **Claims and remote access**: More specific denial messages, plus an off-by-default server option to allow remote tools with unsupported claim APIs. Supported claim permission checks still apply.

## Visuals & UI

- **Tintable particles**: Added `!`, `?`, `...`, `×`, `⚡`, metal debris and glitch sparks, with RGB, size and lifetime controls. Refined symbol shapes.
- **Tracer trails**: Guns, Arrow Launchers, Mortars and Hovering Homing Projectiles can use tracers with adjustable color, length and width.
- **Hit particles**: Ordinary and Survival Heart Cores can customize particle type, count and spread for structure hits.
- **Radial blur**: Remains visible when facing away from its source, transitions smoothly when turning toward it and retains distance falloff.
- **Previews and layout**: Part Break can preview both the monitored substructure and break region. Shortened several preview instructions, aligned controls and page numbers, and updated both manuals.

## Compatibility

- **Let it Walk!**: Route damage from connected legs and related attached structures to the main core. Deduplicate each projectile or explosion per core across parts and Hybrid receivers.
- **TaCZ Tactical Breaching**: Restore missing health damage from valid non-core structure hits canceled by Tactical Breaching, while retaining its block destruction and penetration handling.
- **Create: Gunsmithing / NTGL**: Added structure damage compatibility for projectiles, rockets, grenades and melee.
- **LittleTiles**: Built-in optional client mesh recovery requests bounded native rebuilds for identified mesh-loss or upload-failure paths, addressing some invisible-tile cases. Configurable and enabled only when dependency versions and interfaces match.

## Bug Fixes

- Fixed newly placed multi-part blueprints being treated as disconnected before joints recover, causing mark loss or premature limb cleanup. Automatic activation waits for required connections and marks.
- Fixed the marked-part operation in Part Break and Damage Accumulation Trigger potentially disconnecting the player.
- Fixed mixed world/structure coordinates in Arrow Launcher collision queries, preventing oversized queries and missed targets.
- Entity Hitboxes ignore potion statuses and ignition timers. Repeated contact attacks share a hurt window across receivers, while direct impact damage remains available.
- Improved cleanup retries and native Sable cleanup fallback, retaining pending records when individual tasks fail.
- Isolated Java addon linkage errors during module startup, execution and shutdown, preserving settings and allowing other modules and cores to continue.
- Fixed inconsistent initialization of arena spawn/defeat announcements across copying, saving and reloading.

## Addon Support

- Added a **Java module API** for registering modules, properties, marks and server behavior.
- Added **JSON Datapack modules** and examples, supporting `/reload` and up to eight numeric options per module. Missing definitions retain existing settings and can resume when restored.
- Java addon and Datapack modules can be disabled per core type; existing global disable lists remain effective.
